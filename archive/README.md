# Vibra archive

Everything in this directory is historical and unsupported. It is retained to
explain earlier decisions, recover experiments, and compare behavior while the
v1 implementation is designed. It is not part of the active specification or
roadmap.

## Snapshots

- [`pre-v1/`](pre-v1/ARCHIVE.md) — compiler, runtime, tests, schemas, standard
  library link, examples, workflows, skills, plans, research, and documentation
  that existed immediately before the 2026-08-22 soft reboot.

Archived code MUST NOT be imported by the new implementation. A useful idea is
reintroduced only through the active specification and new conformance cases.
