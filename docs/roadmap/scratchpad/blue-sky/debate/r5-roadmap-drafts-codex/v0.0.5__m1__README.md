## Gate

Every transition has independently authored source cases and typed outcomes. Pending work/queues/mailboxes have explicit bounds. Timeout/cancel does not mean a submitted write did not happen. Scope cleanup states whether each local task joins/ends/remains recorded and preserves external outcome information.

Fixed virtual-time schedules reproduce outcomes and causal origins on interpreter/native. Both suites, schemas and approval/driver checks pass. No crash durability is implied before M2 qualifies a selected profile.

## Exclusions

No remote framework, hidden exactly-once interpretation, unbounded detached task, general deadlock detection or state resurrection after scope exit.
