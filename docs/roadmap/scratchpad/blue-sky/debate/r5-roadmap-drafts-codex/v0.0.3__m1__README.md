# v0.0.3 M1 — Complete native lowering and runtime profile

Status: planned. This completes the supported K3 sequential native profile from v0.0.2 M4. Old-profile scaffolding is reusable, not a completed gate.

## Prerequisites and entry points

Require approved source/type/effect/runtime/diagnostic contracts, a complete source-form disposition map, v0.0.2 language/grant/native-slice exits, checked-IR/registry/ABI identities and protected inputs. Begin [target qualification](feasibility.md) before widening support claims.

vibra-lower consumes immutable checked IR; vibra-exec verifies execution IR; vibra-nexus-eval steps it; vibra-codegen consumes only a verified wrapper; vibra-nexus-bridge exposes the runtime interface; vibra-build links. Semantic phases acquire no source files, shells or dependencies. Workspace/build adapters own acquisition.

Reconcile the as-built descriptor with revised complete block/frame metadata, entry result, registry/driver/grant requirements and origin mapping before dependent packages. Do not guess application failure from a variant named err or treat a descriptor as a proof.
