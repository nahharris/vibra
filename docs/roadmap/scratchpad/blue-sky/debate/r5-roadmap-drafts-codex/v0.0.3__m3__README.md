## Manifest and admission

Use the canonical build contract in the [package chapter](../../../spec/04-programs-and-packages.md#build-products). A mutable store head grants no authority. Descriptor/manifest checks cover ABI, registry, driver/world/policy requirements before source entry. Static row/proof reports stay bound to exact code even when rows are erased in execution. No live bearer grant, callable or Intent is serialized as restorable authority.

Compute identities in prerequisite order: finalized inputs, object, executable, manifest payload, signature. A payload excludes its own hash/signature field; no ring of executable/manifest hashes. Sign after reproducibility comparison. Changed pinned tooling is a changed identity, not a false cache hit.
