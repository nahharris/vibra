## Gate

Both suites pass. Scope cleanup, lifetime, ordering/backpressure, typed outcomes and authority hold on interpreter and native execution. Contexts have exclusive access; no arena offset crosses a broker boundary. Replay is at kernel actions, not instruction/quota counts; production worker interleavings need not have one global event order.

Review runtime/unsafe/broker boundary and version event/schedule schemas. Not-run instrumentation is not race-freedom proof. Gate 2 requires useful library integration and bounded concurrency evidence; neither is inferred from compiling workers.

## Exclusions

No shared arena, migration, stealing, remote transport or hard real-time scheduling. Durable/slow service behavior follows in v0.0.5.
