## Prerequisites

v0.0.4 supplies typed protocol outcomes, scopes/lifetimes, bounded mailboxes, simulation and qualified native workers. Existing authority/approval, interpreter/native parity and build provenance remain regression gates. New behavior is specified with diagnostics/schemas before code.

## Release gate

### Gate 3 acceptance

A document service has a state owner and persistence worker: request save revision 1, edit to revision 2 while the write is pending, then deliver old success. Saved marker may become 1; revision 2 remains unsaved. A mutant applying late acknowledgement to the current revision must fail.

Exercise full/closed/refused requests, duplicate reply, exit while waiting, cancellation before/after dispatch, timeout and ambiguous completion. For a selected durable workflow crash at named boundaries, restart with pinned code/policy/driver identity and reconcile unknown outcomes explicitly. Compare recorded simulation on interpreter/native; actual multicore runs satisfy protocol properties rather than a universal event sequence.

## Exclusions and status

No exactly-once external effect, universal deadlock freedom, distributed consensus/deployment, automatic schema/nominal migration, hidden retry or general service-correctness proof. UI remains future work.

No gate is complete from this rewrite. Publish commands, versions, states explored, gaps and both-suite counts before tagging. Independent expectations and protected oracle code remain mandatory.
