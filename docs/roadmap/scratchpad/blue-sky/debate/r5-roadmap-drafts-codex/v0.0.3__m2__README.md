## Parity inventory

Enumerate every executable case and each executor/platform status. A matched cell that fails fails the run; a changed corpus cannot vanish from the table. Reidentify old cases for the new K3 profile instead of counting old syntax as current coverage. A stepper pass is not a native-platform pass.

Until cutover, continue only the declared wasm-transition-v2 cases on its retained old ABI. New K3 grant/guard/entry behavior it cannot express is explicitly unsupported and not passed. Full native qualification does not depend on inventing a replacement Wasm capability ABI.

## Exit gate

Zero pending/failed supported native-v1 executable cases on all three actual platforms, both independent suites green, current machine schemas/source maps and v0.0.2 approval/repair regressions. Independent expectations are reviewed from the specification, not regenerated from new output.

Document which host assumptions are tested and trusted. A user-data-triggered guard/division/observation trap is not an acceptable new-profile expectation; defect-injection tests are separate. Yield must not duplicate a dispatch, but this is not exactly-once external behavior or crash durability.

## Exclusions

No remote targets, public cross-compilation, optimizer, actor workers or general cost proof. M3 packages qualified behavior and removes Wasm.
