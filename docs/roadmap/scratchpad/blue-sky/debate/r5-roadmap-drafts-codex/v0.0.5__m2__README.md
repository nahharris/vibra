# v0.0.5 M2 — Selected journal and recovery profiles

Status: planned. M1 supplies the explicit state machine and outcome/correlation contract. Choose the least needed profile, never universal journaling.

## Profile prerequisite

- none: no persisted recovery claim; ordinary audit/typed outcomes remain.
- ring: bounded diagnostic history with explicit overwrite/loss, not crash recovery.
- durable: versioned retained record and recovery protocol for named state/operations, with flush/crash/replay/reconcile boundaries.

Before code specify record version, statement/code/policy/driver identities, redaction/access, stable invocation/correlation references, atomic/flush boundaries, recovery order and unsupported upgrade. Do not persist live grants, offsets, callables or Intents as authority. Reacquisition goes through approved binding/issuer recipes.

| Step | Complete slice | Validation |
| --- | --- | --- |
| N5.2.1 | Profile-specific record. | Bounded ring overwrite or durable append/flush, malformed/version-incompatible refusal, secret/redaction cases. |
| N5.2.2 | Crash campaign. | Before submission, after possible submission, after reply, before/after durable commit; distinguish not-submitted/known/unknown. |
| N5.2.3 | Recovery/reconciliation. | Pinned restart, legitimate authority reacquisition, explicit external-outcome reconciliation; no blind retry. |
| N5.2.4 | Upgrade/admission failure. | Mismatched code/policy/schema or unavailable required grant rejects; no implicit nominal migration/replay under changed meaning. |

## Gate

Independent crash/record cases qualify each advertised profile on models and actual native persistence adapters. Per-operation duplicate safety is explicit; @once is not cross-crash exactly once. State durability/OS assumptions are recorded, not inferred from process success. Both suites and service/approval regressions pass.

A profile unnecessary for the workload may remain explicitly unsupported; absence is not recovery support.

## Exclusions

No distributed transaction/consensus, universal event sourcing, replay of every effect, bearer-token persistence or silent recovery across arbitrary upgrades.
