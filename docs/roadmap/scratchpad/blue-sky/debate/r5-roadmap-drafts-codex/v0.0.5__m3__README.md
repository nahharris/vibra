## Exit gate

Gate 3's document-save and every advertised failure/recovery path pass. Exploration is bounded evidence, not universal correctness. Redaction/policy/source/driver identities are inspectable. Record commands, commit, platform, counts and gaps; never regenerate expectations from candidate output.

## Exclusions

No unbounded checking, all-schedules proof, static must-reply/termination guarantee, exactly-once external action, distributed recovery or authority amplification.
