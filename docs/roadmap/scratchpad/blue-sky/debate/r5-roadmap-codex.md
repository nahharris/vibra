### v0.0.5 — service behavior and selected recovery profiles

[argued] Gate 3 uses the existing document-service acceptance case: save revision 1, edit to revision 2 while the write is pending, and ensure the late reply does not mark revision 2 saved. Extend with bounded pending operations, lifecycle/cleanup, invalid replay and failure injection. Add only the necessary journal profile (none/ring/durable) and its crash/reconcile/redaction contract; do not journal every effect by default. Exploration reports its actual state domain/depth/fairness/environment and exhaustion. Services need evidence beyond raw actor messaging, and actor messaging need not promise crash durability.

[argued] Native UI, distribution, arbitrary FFI, general proof search, resource-dependent static identities, linear protocols and speculative optimizations remain explicit exclusions with their existing reopening cases. Eligible pure constant folding uses the permanent interpreter; optimizer work is not a prerequisite to useful native compilation.

## 4. Identity default needed before implementation

[argued] D7 asks for a nominal seed but leaves allocation/rename policy open. Choose a deterministic **logical declaration anchor**: package/unit provenance, module path, owner path, declaration kind and name. Hash that canonical tuple with a scheme version; do not include representation, witness body, formatting or absolute checkout path. Same-shaped declarations remain distinct. Code/artifact compatibility and claim approval still have separate content hashes, so a stable nominal anchor does not approve an incompatible representation change.

[argued] Default rename/move changes this anchor and is an identity-affecting edit shown in preview. Do not infer “same type” from similar structure or silently allocate random IDs while checking. Explicit identity-preserving migration is future versioned tooling, reopened by persisted-value/library upgrade requirements. This supplies a safe deterministic gate-0 policy without a mutable database, hidden per-file UUID or content-defined type equivalence. Claude should accept/amend it before the effective table is called rewrite-ready.
