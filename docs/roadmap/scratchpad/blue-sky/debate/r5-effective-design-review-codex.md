## 2. Compact additions needed to preserve agreed guarantees

[argued] Add these short entries or explicit source pointers; the full 741-row mapping need not be duplicated:

- **Protected evidence boundary (B3, K3 syntax review section 11):** protect test bodies, oracle helpers/fixtures, selection and runner/policy versions, distinguish candidate code, and pin both for each run. A manifest protecting only signatures is insufficient. Doc text is not executable proof; the X6 historical keys are unchanged.
- **Scope-policy boundary (A-24, SP):** policy data creates no authority; correlation-preserving rules, retained parent intersection, shared limits, no cached intermediate directories between invocations, object-lifetime/hard-link consent limits, HTTP component-prefix plus exact/any query, and Windows M0 feasibility before relying on the adapter. Safe unsupported fallback does not pass the useful program gate.
- **Initial concurrency implementation (A-17/A-23, NH):** shared actor kernel/executors, copied neutral messages, fixed pinned workers/exclusive context ownership; scoped child/join and bounded ordered parallel map are first user-facing APIs; long-lived actors need explicit lifetimes. No measured speedup, shared arena, migration, stealing, must-reply or crash-durability guarantee.
- **Diagnostic/evidence status (L9, E4/E5):** bounded versioned outputs pin checked revision and tool/driver/policy identities; refuted/unknown/unsupported are not success. Tests do not prove universal contracts; proof claims name their fragment, checker and TCB.
- **Full-cycle delivery (execution.md/N1):** specification rules, host tests, independent Vibra cases, diagnostics/schemas and real-profile behavior land together. A parser-only feature or syntax pilot is not the gate-1 program/distribution test.

[argued] Section 12 should say **the full current K3 package has not yet been tested on model writers**, and distinguish that from the finite Python countermodels/source audits already recorded. The Windows adapter and production static checker remain unimplemented/unqualified in this review. Existing Nexus Windows evidence is historical partial machinery, not a run of the new design. None of these summary additions claim stronger evidence.
