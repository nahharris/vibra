# M2 step 36 — the release program

The release program of [v0.0.2](../../README.md#release-gate), items 1 and
2: a command-line program that reads the `.txt` notes in a directory named
by its argument, shows their line counts, writes a log under another
directory, and writes a metric when `GATE_METRICS` names a third. It is
[`examples/gate/`](../../../../../examples/gate/). Its pure modules are the
library [`examples/gate/gate-pure/`](../../../../../examples/gate/gate-pure/),
a path dependency beneath the project, as 04 "Project file" requires of a
path.

The showings run through the built binary in
`crates/vibra-cli/tests/it/gate.rs`, on the program and on variants of it
that each test writes. The same program under a world is the corpus case
`V2-GRANT-release-optional-absent`.

## The program

- `src/gate/main.vib`: the entry `main`, the optional metric (`report`),
  and the log callback, an anonymous `proc` of row `{DirWriteText}` that
  closes over `logs` and nothing else.
- `src/gate/tally.vib`: `listNotes` (row `{DirList}`), `readNotes` and
  `readNote` (row `{DirReadText}`, a recursive walk over `Iter.next`), and
  `record`, which takes the callback as
  `Proc({Str} Result(Void FsError) {DirWriteText})`. A read that fails is
  logged with its error and not counted.
- `tests/main.vib`: seven tests, each `takes {world: TestWorld}` and
  obtains every grant the entry takes from that world: the summary, the
  log's text, a present metric, the absent metric, a denied request, an
  exhausted limit, and a usage error.

`EnvReadArgs` for `@notes.list` and `@notes.reader`, `EnvReadVar` for
`@metrics`. The entry takes `vars` and never performs it, which needs no
entry of the list (03 "Target admission").

## Constructions the checker rejected

Each was written, rejected by `vibra check`, and repaired as follows.

| Construction | Diagnostic | Repair |
| --- | --- | --- |
| a reassignment `metrics = Option.some(value: metricWriter)` inside an `if`, to choose the metric directory of a test | `@syntax.invalidForm` ("an `if` is `if condition then body [else body] endif`") | the pure function `chosen(wanted writer)` |
| `let Result.err(error: error) be outcome endlet` inside the `else` of a `let Result.ok(value: _) be outcome`, to name the error of the metric write | `@pattern.refutableBinding` | a `match` over `outcome` |
| a test that names `main.main` and no `use @std.assert` (the grant-from-data variant of `gate.rs`) | `@module.missingRequiredImport` | the variant imports `@std.assert` |

`fmt` changed the layout of `src/gate/main.vib`, `src/gate/tally.vib` and
`tests/main.vib` once (a long `let` broken before `endlet`, an anonymous
`proc` on its own line); the checked-in files are its output.

## The showings

Each command runs in a directory that holds `gate/` (a copy of
`examples/gate/`), and the empty directories `logs/` and `metrics/`, and
`notes/` with the files the section names. The variants edit `gate/` as
the section says. Every envelope is the one line `vibra` wrote; each
validates against the published schema in `gate.rs`.
