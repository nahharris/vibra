# Implementation plans

This directory contains dated, task-oriented implementation plans. Plans are
working records for execution and review; they do not override the accepted
contracts in [`../decisions/`](../decisions/) or the current behavior described
in [`../index.md`](../index.md).

Use the naming pattern `YYYY-MM-DD-short-topic.md`. Keep a plan self-contained,
mark completed steps, and update or archive it when the design changes.
